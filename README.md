## `01 / SIGNAL`

I work on cryptography, protocol design, and performance-aware systems. I am drawn to the point where a clean abstraction meets a hostile runtime—where correctness has to survive state, concurrency, measurement, and adversarial assumptions.

The recurring question behind my work is not only **“does it work?”**, but **“what must remain true for it to keep working?”**

```text
identity     Gabriel Faria
coordinates  Belo Horizonte, Brazil
focus        cryptography × systems × algorithms
method       model → build → measure → attack assumptions → verify
bias         explicit invariants, narrow trust, reproducible evidence
```

## `03 / SELECTED TRANSMISSIONS`

### [`0x01` Maximum Independent Set Solver](https://github.com/fariamg/Maximum-Independent-Set-Solver)

Meet-in-the-middle and SOS dynamic programming applied to an NP-hard graph problem, with explicit performance and tie-breaking behavior.

### [`0x02` Logistics Scheduling Simulation Framework](https://github.com/fariamg/Logistics-Scheduling-Simulation-Framework)

An event-driven C++ simulation system for package routing, warehouse scheduling, graph algorithms, and experimental performance analysis.

### [`0x03` Adaptive Sorting Algorithm Framework](https://github.com/fariamg/Adaptive-Sorting-Algorithm-Framework)

A C++ framework that selects sorting strategies from runtime characteristics and backs the decision with calibration and measurement.

### [`0x04` Urban Infrastructure Solver](https://github.com/fariamg/Urban-Infrastructure-Solver)

Graph-based analysis of shortest paths, critical paths, and critical edges in large transportation networks.
